## Foundation

Windows 三页配音工具。视觉规范见 [DESIGN.md](DESIGN.md)。用 {colors.accent} 标记当前步骤和主操作。

## Information Architecture

| 页面 | 完成的任务 |
| --- | --- |
| 写稿 | 粘贴、导入或编辑正文，查看字数 |
| 试音 | 搜索音色、设置语速、生成试听、播放和停止 |
| 导出 | 核对字数、音色和语速，选择文件路径，定位最近成品 |

## Voice and Tone

页面标题使用动词。导出前显示当前参数，导出完成后显示真实保存路径。

## Component Patterns

三个步骤随时可切换，共享同一份文稿和声音参数。导出结果可装载到试音页的播放器。

## State Patterns

试听完成时，若当前位于试音页则自动播放。切离试音页会停止播放。停止或自然结束后可从头重播。处理中显示进度和当前任务，并禁用重复提交。

## Interaction Primitives

Ctrl+O 导入文稿并回到写稿页。Ctrl+S 可从任意页保存 MP3。播放和停止按钮根据当前音频状态启用。

## Accessibility Floor

导航、播放和停止均提供文字标签。隐藏页不参与 Tab 导航。当前步骤使用配色提示，页面标题明确当前任务。

## Key Flows

几个叶子在写稿页导入文稿，转到试音页调整语速，试听后按停止。最后在导出页核对参数、选择保存位置，再从最近导出返回播放器检查成品。
